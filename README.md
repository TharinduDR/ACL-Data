# ACL-Data

This repository contains data collected from the [ACL Anthology](https://aclanthology.org/) for the paper **"Reassessing the State of Linguistic Representation Across NLP Research Areas."**

The study analyses more than 60,000 NLP publications to examine how research attention is distributed across languages and **29 NLP research areas**. For each paper, we identify the languages studied and research areas addressed using vision-language models.

## Data

The repository is organised by publication year, with directories from `2015/` to `2026/`.

We use publication counts to measure research attention rather than language-resource availability. The paper compares global and area-specific linguistic representation using six classes: **Winners, Underdogs, Rising Stars, Hopefuls, Scraping-Bys, and Left-Behinds**.

## Corrections

Automatic metadata extraction may contain errors. If you identify an incorrect language or research-area assignment, please open a GitHub issue or submit a pull request.
